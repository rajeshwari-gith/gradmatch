# Program data

`programs.csv` has one row per program:

| Column | Meaning |
|---|---|
| university, program, field, state | Who and where (state is a 2-letter code) |
| tuition_in_state, tuition_out_state | Tuition per year in dollars |
| living_cost | Living cost per year for the state (rent, food, transport). From the MERIC cost of living index × $200: https://meric.mo.gov/data/cost-living-data-series |
| avg_gpa | Average GPA of admitted students |
| website | Program or department page |
